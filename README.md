# МираМе · ХолСтори — сайты-визитки с каталогом картин

Одна кодовая основа на Django для двух **независимых** сайтов:

| Установка | Тема | Бренд | Настройка |
|---|---|---|---|
| A | «Голубая акварель» | МираМе | `SITE_THEME=a` |
| D | «Арт-пространство» | ХолСтори | `SITE_THEME=d` |

У каждой установки своя база, медиатека, админка, ключи API и домен (раздел 1.1 ТЗ).
Общей базы, общей админки и синхронизации нет.

## Что умеет

- Каталог: рубрики любой вложенности, картины в трёх состояниях (в наличии, под заказ, продана/SOLD), фото целиком без обрезки, галерея с увеличением.
- Одна форма заявки для всех сценариев. Контекст (картина, рубрика, «заказать похожую», сертификат) определяется на сервере. Есть поле желаемого размера: общий список из 20 форматов или свои размеры для конкретной картины.
- Заявки хранятся в админке со статусами «Новая», «В работе», «Закрыта». Уведомления уходят на почту, но заявка сохраняется, даже если письмо не отправилось.
- Карта «География наших продаж» показывает только подтверждённые города. Справочник из 343 городов по 10 странам уже в репозитории, см. `docs/geography.md`.
- RU в корне сайта с кириллическими ЧПУ, EN под `/en/` со своими адресами и текстами, взаимный `hreflang`.
- SEO из админки:
  - Title в формате «Бренд | …», description, H1, noindex, Open Graph;
  - автоматический `sitemap.xml`, редактируемый `robots.txt`;
  - 301-редирект при смене адреса, без цепочек;
  - JSON-LD (WebSite, Organization, BreadcrumbList, Article);
  - коды подтверждения Яндекс Вебмастера и Google Search Console.
- Все надписи на сайте, включая надписи поверх баннера, редактируются в админке. Кнопки, поля и статусы — в разделе «Надписи интерфейса».
- API импорта фотографий по рубрикам: ключи с отзывом, журнал, повторная отправка без дублей. К API есть загрузчик `tools/uploader.py`.

## Быстрый старт (локально)

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
printf "DEBUG=1\nSITE_THEME=a\nHTTPS=0\n" > .env
python manage.py migrate
python manage.py seed_site          # стартовые тексты, рубрики, SEO, 20 размеров, статьи
python manage.py import_cities      # справочник городов для карты продаж
python manage.py createsuperuser
python manage.py runserver
```

Сайт откроется на http://127.0.0.1:8000/, админка — на http://127.0.0.1:8000/admin/.

Для проверки вёрстки можно добавить демо-картины: `python manage.py seed_demo`. Удалить их: `python manage.py seed_demo --remove`. На рабочий сайт демо-картины не загружайте.

Второй сайт запускается так же, но со своим файлом окружения:
`ART_ENV_FILE=.env.d python manage.py …`, где в `.env.d` указано `SITE_THEME=d` и свой `DATA_DIR`.

## Структура

```
artsite/      настройки (всё берётся из переменных окружения)
core/         общие настройки, надписи, сквозные блоки, размеры, SEO, маршрутизация, редиректы
catalog/      рубрики, картины, изображения, свои размеры
content/      страницы, статьи «Полезное», меню, блоки главной, отзывы, сертификат, студия
leads/        заявки и вложения (вложения лежат в закрытом хранилище)
geo/          справочник городов и реестр geo/data/cities.csv
importapi/    API импорта, ключи, журнал
templates/    common/ — общие шаблоны, themes/a|d/ — переопределения темы
static/       common/ — общие стили и скрипты, themes/a|d/ — стили и шрифты темы
seed/a|d/     стартовое наполнение каждого сайта
tools/        загрузчик фото, сборка реестра городов
docs/         развёртывание, инструкция владельца, API, география, чек-лист запуска
```

## Тесты

```bash
python manage.py test
```

Тесты повторяют критерии приёмки ТЗ:
- адреса, hreflang, canonical, смена домена;
- 301-редиректы, sitemap, noindex, пагинация;
- SOLD, общее и индивидуальное описание, наследование размеров;
- заявки: контекст, размеры, идемпотентность, файлы;
- API: права, дубли, форматы, отзыв ключа.
