# Реестр городов для карты «География наших продаж»

Файл `geo/data/cities.csv` — машиночитаемый реестр (раздел 8.1 ТЗ). Команда `python manage.py import_cities` загружает его в каждую установку отдельно. Импорт **не создаёт продаж**: отметки продаж выключены, их включает владелец по фактическим данным.

## Критерий отбора

Рабочий критерий из ТЗ 0.3: население от 100 000 человек включительно, плюс столицы стран и административные центры регионов первого уровня независимо от численности. Перед рабочим импортом порог и срез источника нужно подтвердить с Заказчиком. Порог меняется параметром `--min-population`.

Страны: Россия, Беларусь, Казахстан, Армения, Азербайджан, Грузия, Кыргызстан, Узбекистан, Таджикистан, Эстония. Туркменистан, Молдова, Украина, Латвия и Литва исключены по указанию Заказчика.

## Источники

- **GeoNames** (CC BY 4.0, https://www.geonames.org/) — через npm-пакет `all-the-cities@3.1.0`. Из него взяты ID, координаты, население и код объекта:
  - PPLC — столица;
  - PPLA — центр региона первого уровня;
  - PPLX — район города (исключается).
- **hflabs/city** (CC BY-SA 4.0, https://github.com/hflabs/city) — официальное русское написание городов России и отметка центров регионов. Сопоставление с GeoNames выполнено по координатам (до 40 км) и сходству названий. Все 173 российские записи сопоставлены без замечаний.
- Русские названия городов остальных стран проверены вручную. Для переименованных городов указано действующее название: Астана, Бохтар, Шабран, Билясувар, Гёйгёль, Габала, Ходжавенд, Дашкесан.

Население взято из GeoNames. Дата переписи в источнике не указана, а дата изменения записи GeoNames за дату переписи не выдаётся. Для спорных по численности записей перед запуском рекомендуется сверка с национальной статистикой.

## Известные ограничения

- В GeoNames Севастополь и Симферополь отнесены к Украине, поэтому в реестр они не вошли. Если нужно, подтверждённый город продажи можно добавить вручную в админке.
- Центры регионов, население которых меньше порога выгрузки all-the-cities (1000 человек), могут отсутствовать. Их можно добавить вручную.
- Полноту на текущую дату реестр по одному агрегатору не гарантирует.

## Как пересобрать

```bash
mkdir /tmp/geo && cd /tmp/geo && npm init -y && npm i all-the-cities@3.1.0
node -e "const c=require('all-the-cities');const s=new Set(['RU','BY','KZ','AM','AZ','GE','KG','UZ','TJ','EE']);require('fs').writeFileSync('atc.json',JSON.stringify(c.filter(x=>s.has(x.country))))"
curl -o hflabs.csv https://raw.githubusercontent.com/hflabs/city/master/city.csv
python /path/to/art/tools/build_cities_registry.py atc.json hflabs.csv /path/to/art/geo/data/cities.csv
```

Есть и альтернативный путь — полная выгрузка GeoNames: `python manage.py import_cities --geonames-dir <папка>`. Русские названия в этом случае берутся из языковых альтернатив `ru`.

Повторный импорт не перезаписывает записи, изменённые вручную, а также отметки продаж, видимость и подписи.

## Крупные города на карте (по умолчанию)

При первом `import_cities` на карте сразу включаются 28 городов с населением более 800 тыс.:
18 городов России и 10 — в странах ближнего зарубежья из справочника (Ташкент, Алматы, Баку, Минск,
Астана, Тбилиси, Шымкент, Душанбе, Ереван, Бишкек). Список и актуальная численность
(Росстат и национальные статистические службы, 2025 г.) — в `geo/major_cities.py`.

```bash
python manage.py map_major_cities --dry-run   # показать список с численностью и источником
python manage.py map_major_cities             # включить отметки (ручные правки в админке не трогаются)
```

Любую отметку можно выключить или добавить в админке («География продаж — города»);
такой город помечается «Изменено вручную», и команды его больше не меняют.
На карте подписи крупных городов в приоритете: если подписи мешают друг другу,
менее крупные скрываются до приближения, точки остаются.

> Отметки включены по решению владельца как тестовые продажи; на рабочем сайте оставьте только подтверждённые города (аудит F-10).

При первом `import_cities` на карте сразу включаются (всего 103 отметки: 83 центра регионов России, 10 городов ближнего зарубежья и 10 городов Китая):

  так как в GeoNames они не отмечены как центры);

Список крупных городов, их численность и источники — в `geo/major_cities.py`.

```bash
python manage.py map_major_cities --dry-run   # показать список
python manage.py map_major_cities             # включить отметки (ручные правки в админке не трогаются)
```

Любую отметку можно выключить или добавить в админке («География продаж — города»).
Если подписи на карте мешают друг другу, приоритет у более крупных городов; остальные подписи
скрываются до приближения, точки остаются.

## Китай на китайском
Названия городов Китая на карте в китайской версии берутся из переводов (`geo.city`, поле `name`/`country`); без перевода — английское название. Лэндинг `/zh/china/` показывает только города с кодом страны CN и приближает карту к их отметкам (атрибут `data-fit="cities"`; на прочих страницах карта работает как раньше).
