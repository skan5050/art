## Проверка заполненности перед запуском

```bash
python manage.py audit_content --strict                       # сайт A
ART_ENV_FILE=.env.d python manage.py audit_content --strict   # сайт D
```

Команда проходит все публичные страницы на обоих языках и сообщает: поля, заполненные только
на одном языке; страницы без H1 или с несколькими H1; пустые Title/Description и выход за
рекомендуемую длину; отсутствие canonical и x-default; изображения без alt; незаполненные
подстановки вида `{brand}`.

- [ ] `seed_demo --remove` выполнен (удаляет демо-работы и демо-отметки на карте).
- [ ] На карте продаж включены только города с подтвержденными продажами.
- [ ] В «Настройки сайта → Формы» решено, нужна ли галочка согласия и ссылка на политику.
- [ ] Телефон, email и мессенджеры заполнены (без них блоки контактов не выводятся).
